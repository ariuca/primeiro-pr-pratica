# Primeiro PR

Repositório de prática para o fluxo de Pull Request no GitHub.

## Sobre

Este repositório foi criado para praticar o ciclo completo: branch, commit, push e pull request.

## Como contribuir

1. Crie uma branch a partir da `main`.
2. Faça suas alterações e escreva um commit descritivo.
3. Abra um Pull Request explicando o que mudou e por quê.
